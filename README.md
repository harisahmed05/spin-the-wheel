# 🎡 Spin the Wheel

A beautiful, interactive spinning wheel for picking random numbers. Perfect for giveaways, classroom activities, or decision-making.

## 🚀 Key Features
- **Fully Customizable:** Input any range (e.g., 1-44) and exclude specific numbers.
- **Auto-Remove:** Numbers are removed from the wheel once picked so you never get the same result twice.
- **Modern UI:** Responsive, dark-themed design with smooth, realistic animations.
- **One-File Setup:** Pure HTML, CSS, and JS—no installation or dependencies required.

*Built for simplicity and speed.*
